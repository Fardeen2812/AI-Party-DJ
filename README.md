# AI-Party-DJ
An AI DJ App for personal party & celebrations (built with Next.js App Router, Gemini AI, and YouTube player).

## Getting Started

1. Create `.env.local` in the project root with your keys:
   ```bash
   cp .env.local.example .env.local
   ```
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   YOUTUBE_API_KEY=your_optional_youtube_api_key_here
   ```

2. Install dependencies and run the development server:
   ```bash
   npm install
   npm run dev
   ```

3. Open `http://localhost:3000` to start using the app.
